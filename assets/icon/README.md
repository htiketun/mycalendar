# Calendar App Icon Design

## Icon Concept

A modern, minimalist calendar icon with the new purple theme.

## Design Specifications:

-   **Size**: 1024x1024 pixels (recommended for app icons)
-   **Background**: Deep purple gradient (#2D1B69 to #3C1C5B)
-   **Main Element**: White calendar grid (3x3 or 4x4)
-   **Accent**: Purple glow effect around the calendar
-   **Date Display**: Show "27" as the date (current date)
-   **Style**: Clean, modern, arcade-inspired

## Color Palette:

-   Background: Deep Purple (#2D1B69)
-   Calendar: White (#FFFFFF)
-   Accent: Electric Purple (#9D4EDD)
-   Glow: Neon Purple with opacity

## Alternative Simple Design:

If you need a quick solution, you can:

1. Use a solid purple background (#9D4EDD)
2. Add a white calendar symbol (📅)
3. Add the text "CAL" in white Orbitron font

## Tools to Create:

-   Figma (free online)
-   Canva (free templates)
-   Adobe Illustrator
-   Or use online icon generators

## File Requirements:

-   Save as PNG with transparent background
-   1024x1024 resolution
-   Place in: assets/icon/icon.png
